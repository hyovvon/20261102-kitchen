# MOMO KITCHEN QR 메뉴판

## 실행 방법
1. 압축을 해제합니다.
2. `index.html` 파일을 크롬 또는 엣지 브라우저로 엽니다.
3. 휴대폰 화면에서도 반응형으로 확인할 수 있습니다.

## 폴더 구성
- index.html : 웹페이지 구조
- css/style.css : 색상, 레이아웃, 반응형 디자인
- js/main.js : 메뉴 출력, 카테고리 필터, 주문 팝업
- assets/ : 실제 이미지 파일

## 수정할 부분
- 메뉴명, 가격, 설명, 알레르기 정보: `js/main.js`의 `menus` 배열
- 매장 전화번호와 주소: `index.html`
- 색상과 글꼴 크기: `css/style.css`의 `:root`

※ 메뉴·가격·주소·전화번호는 실습용 예시입니다.
※ 구글 지도 링크는 MOMO KITCHEN Jinju 검색 예시로 연결됩니다.
※ 주문 팝업은 안내용이며 실제 결제/주문 접수 기능은 연결되어 있지 않습니다.
